# SE Asia & Pacific Research Collaboration Web App

An interactive real-time web application to map and manage research and teaching collaborations across Southeast Asia and the Pacific.

## Features
- **Interactive Leaflet Map:** Displays color-coded markers for Science, Engineering, IT, Cross-Disciplinary, and Teaching collaborations.
- **Multi-User Realtime Sync:** Powered by Firebase Firestore (`onSnapshot`), allowing multiple facilitators and researchers to add pins simultaneously.
- **Click-to-Pin:** Click anywhere on the map to automatically populate latitude and longitude coordinates in the input form.
- **Filtering & Search:** Search collaborations by title, partner institution, lead researcher, or filter by discipline and target country.
- **Export Data:** Export all plotted projects to JSON format for reporting and archiving.

## Quick Start
1. Extract `sea_pacific_collaboration_app.zip`.
2. Open `index.html` in any modern web browser (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge).
3. No build tools, Node.js, or server setup required — all dependencies are loaded via CDN.

## Target Use Case
Designed for university facilitators running roundtables, workshops, or strategic planning sessions focused on building up SE Asia and Pacific research capabilities.
